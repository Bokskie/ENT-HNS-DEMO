Button Guide

💾 SAVE & EDIT YOUR WORK (Draft Files)

💾 Save Draft: Saves your current work as a file on this computer/tablet. Open this file later to continue editing the report.

📂 Open Draft: Restores a saved draft file so you can keep editing an existing report.

📄 FINAL COPY & PRINTING

📄 Save PDF: Creates the final PDF copy of the completed report. Use this for printing, sending, or archiving.

🖨️ Print: Opens the print dialog to print the report directly on paper.

OTHER BUTTONS

🆕 New Form: Starts a blank form of the same type for the next patient. Your current entries are cleared but you can undo this.

🗑️ Clear Form: Removes all fields and images to start fresh (you can undo this).

❓ Help: Shows this button guide.

🎓 Tutorial: Walks you through the main buttons one by one.

💡 Tip: Always use Save Draft while you are still working on a report. Use Save PDF only when the report is finished.
